# ② 多层图谱展示 —— 手动使用说明

> 静态拼图（raw / ST / APTW）+ 交互式预览；底层算法走 `03_Python_全链路\函数库\cest_display.py`。
> 对应 MATLAB 的多层拼图脚本。**只处理一个病例、一次一张图。**

---

## 一、先记住两件事

| | |
|---|---|
| **必须** | `PROJ\00_掩模\<病例>\Mask.mat`（**去噪掩膜**，⑧ 的产物）。没有 → 会被拦下，提示先跑 ⑧ |
| **不用** | `ROI_total.mat` / `ROI<k>.mat`（那是 ③ 后处理用的，本模块一行都不读） |

数据用 `img_interp（X,Y,层,频）`。如果输入是 ① 的重建结果（只有 `s0/ssat/w_offset`），
本模块会**自己生成一次** `img_interp` 并缓存到 `02_展示\<病例>\_cache\`，之后复用、不再重算。

**LD 暂时不能用**：选了 LD 会被拦下并提示「请先完成 ④ 逐体素LD」。等你 LD 做好我再打开。

---

## 二、参数（② 页「参数」区）

| 参数 | 默认 | 说明 |
|---|---|---|
| `输入` | — | 重建结果目录（推荐），或含 `img_interp` 的目录/`.mat` |
| `病例名` | 自动 | 输出到 `PROJ\02_展示\<病例名>\`；取掩模也按这个名字找 |
| `图类型` | APTW | `raw` / `ST` / `APTW`（LD 暂拦下） |
| `目标频偏 ppm` | 3.5 | APTW 常用 3.5；ST 可用 −1.2 / 2 / −3.5 等 |
| `每行子图数` | 5 | 20 层 + 5 → 4 行 × 5 列 |
| `色标策略` | manual | manual = 照 MATLAB 手输（留空则用常用口径）；另有逐层/全局 5~95% 作参考 |
| `色标下限 / 上限` | 留空 | 留空时：ST→(0.15,0.35)、APTW→(−0.05,0.03)、raw→自动 |
| `掩模文件` | 自动 | 自动找 `00_掩模\<病例>\Mask.mat`；可手动指定 |
| `用掩模压背景` | 勾 | 口径 `.*Mask − (~Mask)`：掩模外强制 −1（与 MATLAB 一致） |
| `层` | 留空 | 留空 = 全部 20 层；可填 `1,3,5` |
| `保存分辨率` | 300 | png 的 dpi |

---

## 三、P1：出静态拼图

1. 选好 `输入`（指到 `PROJ\01_重建\c1` 这种重建结果目录最省事）→ `病例名` 自动填 `c1`；
2. 确认下面面板写着 `掩模：Mask.mat（00_掩模\Mask.mat）`（没有就先去 ⑧ 画）；
3. 选 `图类型` / `目标频偏` → 点 **【开始】**；
4. 产物在 `PROJ\02_展示\<病例>\`：

```
APTW 3_5ppm_combined.png     拼图（20 层网格 + 底部 colorbar）
APTW 3_5ppm_combined.mat     变量 data (X,Y,层) + layers + caxis_range（给后续/对拍用）
APTW 3_5ppm_combined.json    参数留痕（模式/频偏/色标/层数/来源）
_cache\0.7ut_img_interp.mat  中间数据（280MB，只生成一次，之后复用）
```

- **名字就是这几个字**：`{图类型} {频偏}ppm_combined.{png,mat,json}`，小数点变下划线
  （`3.5` → `3_5`）。**不要手改**，后续 ③ 和批处理都按这个名字找。
- **同名重跑会自动备份**：先存一份 `APTW 3_5ppm_combined.bak_<时间戳>.png/.mat/.json`，再写新的。
- 第一次跑（要生成 `img_interp`）约 15 s，之后同一病例 2~3 s。

---

## 四、P2：交互式预览

② 页面板里点 **【打开图谱预览…】**：

- **左「层览」**：20 张缩略图，点哪层看哪层；
- **中「画布」**：滚轮缩放、中键拖动平移（只看，不能画）；
- **右「数据」**：换 `图类型` / `目标 ppm` / 勾掉「用掩模压背景」→ 立刻重画；
- **右「显示」**：
  - `色标` 下限 ~ 上限：改完**立刻刷新**（只影响观感）；
  - **【自动】**：取「`img .* Mask`（背景=0）里非 0 体素」的 5~95% 分位（与 MATLAB 口径一致）；
  - `色图`：jet（首行黑）/ 灰度 / 彩色 viridis —— **只影响看图**，导出一律 jet（首行黑）；
  - `每行子图数`、`分辨率` 决定**导出**的拼图布局；
- **【导出当前所见】**：把现在这张（当前模式/频偏/色标）按同样的命名写进
  `02_展示\<病例>\`。**预览看到的 = 导出的 = 【开始】出的**（同一条保存路径，实测
  `max|diff| = 0`），同名照样先备份。

## 五、报错 / 提示

| 提示 | 怎么办 |
|---|---|
| 「② 需要去噪掩膜…」 | 先去 ⑧ 画好/载入掩模（或在「掩模文件」里指定） |
| 「LD 待接入…」 | 选 raw / ST / APTW；LD 等 ④ 做好再开 |
| 「输入里没有 img_interp，也不是重建结果目录」 | `输入` 指到 ① 的重建结果目录，或含 `img_interp` 的目录 |
| 「掩模文件不存在」 | 清空「掩模文件」让它自动找，或重指路径 |

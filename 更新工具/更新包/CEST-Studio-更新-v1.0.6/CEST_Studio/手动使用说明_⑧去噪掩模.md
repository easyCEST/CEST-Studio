# ⑧ 去噪掩模 · 手动使用说明

> 适用版本：CEST_Studio v0.3（2026-10-02）
> 相关代码：`app\modules\m_roi.py`、`app\dialogs\mask_canvas_dialog.py`、`app\widgets\mask_canvas.py`
> 对照脚本：`tools\validate_mask.py`

一句话：**画一张「组织/肝脏」的圈，让程序算出「噪声 SNR 掩模」，两者相乘就是最终去噪掩模
`Mask = liverMask × snrMask`，存到 `PROJ\00_掩模\<病例>\`，② 出图和 ④ 逐体素LD 会自动用它压背景。**

---

## 一、数据是怎么选的（这一节最关键）

### 1.1 第一步：拖入「输入总目录」→ 自动识别类型

⑧ 能直接用的识别类型：

| 识别结果 | 说明 | ⑧ 可用 |
|---|---|---|
| 已重建结果（单病例） | 目录里有 `s0.mat` + `ssat.mat` + `w_offset.mat` | √ |
| 已重建目录（多病例） | 下面一层层是病例文件夹 | √ |
| 展示输入（img_interp） | 目录里有 `0.7ut_img_interp.mat` 等 | √ |
| ROI / 掩模目录 | 有 `Mask.mat` / `liverMask.mat` / `Thmask.mat` | √ |
| 项目目录 PROJ | 直接含 `00_掩模 / 01_重建 / …` | √ |
| 后处理结果 | 有 `full_interp_*/sliceN/Self_corr/V_exp.mat` | √ |
| 原始 DICOM | 只有 `.dcm` | **✗ 先跑 ① 重建** |

### 1.2 第二步：「底图」这个参数自动填什么

按下面的顺序决定（`m_roi.suggest()`）：

1. 如果 **`PROJ\01_重建\<病例>\s0.mat` 存在** → 底图就用它（**优先级最高**）；
2. 否则识别为「已重建结果 / 展示输入 / 掩模目录 / 后处理结果」→ 底图 = 你拖进来的那个目录；
3. 否则识别为「已重建目录（多病例）」→ 底图 = `输入目录\<病例>`；
4. 都不是（比如原始 DICOM）→ **底图留空**，你要么先在 ① 跑重建，要么手动把「底图」指到
   含 `s0.mat`（或 `0.7ut_img_interp.mat`）的目录。

**病例名**默认取识别到的第一个病例（如 `c1`），产物落到 `00_掩模\<病例>\`；可以直接手改。

### 1.3 第三步：读底图时按这个顺序找文件

给定一个目录（或直接给 `.mat`），依次找：

```
① s0.mat        → 变量取 s0，没有就取 S0
② S0.mat        → 同上
③ 0.7ut_img_interp.mat → 0p7P_interp.mat → 0p7N_interp.mat
   → 2APT_interp.mat → 0.7ut_img_raw.mat
   变量取 s0/S0；顺带读 img_interp + w（这样才能切「Z @ ppm」底图）
④ 都不在 → 报错：「读不到底图 s0。⑧ 需要一个含 s0.mat 的目录…」
```

维度会归一成 **3D `(X,Y,层)`**（末尾或多出来的单帧维会被 squeeze 掉）。

### 1.4 SNR 用哪张图算？**永远用「S0 层间平均」**

和 MATLAB 完全一致：

```
img_mask_base = mean(S0, 3)          ← 所有层的 S0 求平均，得到一张 2D 图
```

⚠️ 画布上的「底图」下拉框（S0 逐层 / S0 层间平均 / Z@ppm）**只影响你看图，不影响计算**。
也就是说：噪声 σ 和阈值永远按「层间平均」那张算，跟你当前在哪一层无关。
画布层览的第 1 项 `★ 全层平均` 就是这张图（选它 = 底图切到层间平均）。

### 1.5 掩模从哪来（跑「开始」时的优先级）

```
参数「载入已有掩模 .mat」填了  →  用这个文件（面板上的两个按钮会自动帮你填）
否则：
  画布画过（self._draw 有内容）→  用画布的结果
  再否则  →  用面板上【载入已有掩模…】/【从输入目录找】载入的内容
  两者都没有  →  拦下不让跑，提示「还没有掩模」
```

文件里的变量按这个口径认：

| 文件里的变量 | 当作什么 | 备注 |
|---|---|---|
| `Mask` / `mask` | **最终掩模**，直接用 | ⑧ 自己存的就是这种 |
| `liverMask` | 组织/肝脏掩模 | |
| `snrMask` | SNR 掩模 | ⑧ 存的 |
| `Thmask`（且没有上面那些） | 按 **MATLAB 口径**当 SNR 掩模 | `GenerateThmask.m` 写的就是它 |
| 只有 SNR 掩模、没有 liverMask | 直接当最终掩模 | 会打提示，方便「拿旧掩模来去背景」 |

**σ（噪声阈值）的优先级**：

```
参数「噪声 σ（0=用画的噪声区）」> 0   →  用这个 σ
否则画布「噪声区」里有画的像素     →  σ = std(底图[噪声区像素])
都没有                            →  snrMask 置全 1（等于不做 SNR 过滤），日志会提示
阈值 = SNR 系数 × σ     （SNR 系数默认 15）
```

### 1.6 输出到哪 / ② 怎么拿到

- ⑧ 输出：`PROJ\00_掩模\<病例>\{Mask, Thmask, liverMask, snrMask}.mat + roi_meta.json + mask_check.png`
- ② 多层展示取掩模的顺序：**参数指定的掩模文件 → `PROJ\00_掩模\<病例>\Mask.mat` → 输入目录里的 `Mask.mat`**
  （`app\modules\m2_display.py`，一般不用管，它自己会找到 ⑧ 的产物）
- ④ 逐体素LD：`--mask` 指定，或输入目录 / 输出目录里的 `Mask.mat`

## 二、怎么用（三种动线，挑一个）

### 动线 A：手工画一张（最常用）

```
1. 顶部拖入输入总目录（如 …\CEST_result_gui\01_重建），选好「输出总目录 PROJ」
2. 左侧导航点「⑧ 去噪掩模」
3. 点【打开掩模画布…】
4. 目标选「组织/肝脏」→ 工具选「多边形」→ 沿组织轮廓点一圈 → **双击确定**（自动封闭）
5. 目标选「噪声区」→ 工具选「矩形」→ 在背景空气处框一小块（只含噪声、不含解剖结构）
6. 点【算 SNR 掩模】→ 看提示的 σ / 阈值 / 信号体素数是否合理
   （σ 也可以直接手输，比如复现 MATLAB 旧结果：c1=25.7933、h1=16.3333）
7. 点【确定（交给 ⑧ 保存）】→ 回 ⑧ 页，核对「将生成」的文件与输出目录
8. 点【开始】→ 结果面板出日志 → 右边看 mask_check.png 确认图
9. 去 ② 出图，背景应该被压平（掩模外 = -1）
```

### 动线 A′：先要个初值再修（可选）

不想从零画就先点【SNR 掩模 → 复制成 liverMask 初值】（对应 MATLAB「先出 SNR 初值，再手工修」），
再用下面的「选择/拖动」「画笔」「橡皮」改。

### 怎么改形状（多边形是矢量的，能直接拖——同 MATLAB roipoly）

```
· 拖某个顶点        = 改那一个点          （顶点是黄色小方块，鼠标靠近会变白）
· 点住多边形内部拖   = 整个多边形平移
· 右键某个顶点      = 删掉那个顶点（剩 3 个点时不再删）
· 画笔 / 橡皮       = 单独一层「笔迹」，叠在多边形上（拖多边形不会把笔迹弄丢）
· 撤销             = 拖一次顶点、涂一笔、画一个多边形各算一步
· 画歪了           = 双击确定前：右键 / Backspace 撤掉刚点的那个点；Esc 整条取消
```

工具都在**画布上方那排按钮**里：`选择/拖动 | 多边形 | 矩形 | 画笔 | 橡皮 | 笔粗 | 撤销 | 清空本目标 | 适应窗口`。
按钮排右边有一行蓝字，实时写着「当前工具是什么、怎么用」，不用猜。

> 改完 → 【确定（交给 ⑧ 保存）】→ 回 ⑧ 页点【开始】。
> 只改某一层：左边点那一层 → 勾「本层单独保存」→ 再拖 / 擦 / 涂。

画布操作速查：

| 操作 | 怎么做 |
|---|---|
| **选择/拖动** | **拖顶点** = 改那一个点；**点多边形内部拖** = 整体平移；**右键顶点** = 删掉该点 |
| 多边形 | 左键逐个加点；**双击 = 确定**（自动封闭，跟 MATLAB 一样）；右键 / Backspace = 撤掉刚点的那个点；Esc 取消 |
| 矩形 | 按住左键拖动，松开生成（生成的是四点，之后可以拖角微调） |
| 画笔 | 按住左键涂（拖动会沿轨迹插值，不断线）；「笔粗」调半径 |
| 橡皮 | 同画笔，但是擦掉 |
| 撤销 | 【撤销】按钮（留 30 步） |
| 清空 | 【清空本目标】（会问一次） |
| 缩放 / 平移 | 滚轮缩放以鼠标为中心；**中键按住拖动**平移；【适应窗口】复位 |
| 换层 | 左边层览点 `层 1 … 层 20` 里的某一层（底图自动切成「S0 逐层」） |
| 画共用掩模 | 点层览第 1 项 **`★ 全层平均`**，在这张上画一次 = 20 层共用（见下面「20 层都要画吗」） |
| 单独层 | 点某一层 → 勾「本层单独保存」→ 本层的改动只作用于这一层，其余层用「共用」那张；导出时自动合成 3D |
| 半透明 | 「叠加显示 → 不透明度」滑杆；「显示其它掩模」勾选框 |
| 换色图 | 「底图 → 色图」下拉框：`灰度` / `彩色 viridis（≈parula）` / `jet（首行黑）` / `jet`；**只影响观感，不影响计算** |

**色图**：手动选，程序不会替你切。MATLAB 那边三步各自用了不同色图，供参考：

| 画什么 | MATLAB 那边 | 想一样就选 |
|---|---|---|
| 噪声 ROI | `ThreMask_SNR.m` / `denoise_Mask.m` 写了 `colormap(gray)` | 灰度 |
| 组织/肝脏 | `GenerateliverMask.m` 只写了 `figure; imagesc(S0)`，**没设 colormap** → 用 MATLAB 默认 parula | 彩色 viridis（matplotlib 没有 parula，取近似） |
| SNR 掩模 / 器官 ROI / 出图 | `ROIplotSong_0708.m` 的 `colormap([0 0 0; jet(255)])` | jet（首行黑） |

掩模本身与颜色无关（几何多边形算的），所以换色图**不改任何结果**。

### ★ 20 层都要手画吗？不用

MATLAB 当年就是对**层间平均图**画**一个** `roipoly`，存出来的 `liverMask.mat` 是 **(X,Y) 的 2D**，
20 层全用这一张。⑧ 的做法一样：

* 层览第 1 项就是 **`★ 全层平均`**（= S0 的 20 层平均图，和 MATLAB 画掩模那张是同一张图）——
  点它 → 底图切到层间平均 → 在上面画一次；
* 导出时自动把这张 2D 铺满 20 层存成 3D `(X,Y,层)`（② 需要 3D；④ 读 3D 取第 1 层，与 2D 等价）；
* **只有某层组织位置跟平均值差很多**时才单独画：左边点那一层（底图会切到该层）→ 勾「本层单独保存」
  → 再改。那一层用你自己那张，其余层照旧用共用张。

要不要逐层，这么判：

1. 把层览 20 张缩略图从上往下扫一遍，组织轮廓基本对齐就不用管；
2. 或者先出一张共用掩模跑 ②，看有没有哪层被切掉/背景漏进来，再回头单独修那几层；
3. 你这批数据里**第 20 层是边界层**（谱形病态、LD 偏差大，可从 ② 的层列表里排除），别为它费时间。

### 动线 B：已经有现成掩模，只想拷进 PROJ

```
1. ⑧ 页点【载入已有掩模…】→ 选一个 .mat（Mask / Thmask / liverMask / snrMask 任一都行）
   或者点【从输入目录找】→ 自动在下列位置找 Mask.mat / liverMask.mat / Thmask.mat：
       底图目录本身 → 它的上一级 → PROJ\00_掩模\<病例>\
2. 面板摘要会显示载入了哪些变量、什么形状
3. 点【开始】→ 拷进 00_掩模\<病例>\
```

要复现 MATLAB 那套掩模，直接选 `…\<病例>\full_interp_0803\mask.mat`（里面带 `liverMask`），
得到的结果与 MATLAB **逐位一致**（见第四节实测）。

### 动线 C：想复现 MATLAB 旧结果 / 做对照

老结果的口径是「先画噪声 ROI 算 σ，再画组织」，σ 因人而异。要逐位复现：

```
1. 画布 → 「噪声 σ」直接手输 MATLAB 那边算出的 σ（c1=25.7933，h1=16.3333，阈值=15σ）
2. 画布 → 把 MATLAB 的 liverMask.mat 的轮廓当多边形画（或用【载入已有掩模…】走动线 B）
3. 确定 → 开始
4. 复跑对照：python CEST_Studio\tools\validate_mask.py --check --proj <你的PROJ>
```

## 三、参数逐条（⑧ 页「参数」区）

| 参数 | 默认 | 说明 |
|---|---|---|
| 底图（重建结果目录 / s0.mat） | 自动填 | 见 1.2 / 1.3；留空 = 自动取 `PROJ\01_重建\<病例>` |

| **打开掩模画布…** | 打开画布（会用当前 底图/病例 去读 s0，读不到会弹窗告诉你原因） |

## 四、产物与校验

### 4.1 产物（`PROJ\00_掩模\<病例>\`）

| 文件 | 变量 | 维度 | 谁用 |
|---|---|---|---|
| `Mask.mat` | `Mask` | **3D (X,Y,层)** | ② 展示（压背景）、④ 逐体素LD |
| `Thmask.mat` | `Thmask` | 3D | ③ 后处理（Python 口径 = 组合后的最终掩模） |
| `liverMask.mat` | `liverMask` | 画布原样（2D/3D） | ③ 后处理 |
| `snrMask.mat` | `snrMask` | 画布原样 | 备查 |
| `roi_meta.json` | — | — | 底图/层数/σ/阈值/体素数/是否逐层相同/时间/来源 |
| `mask_check.png` | — | — | 三格确认图：①底图+轮廓 ②SNR 轮廓 ③最终掩模叠加 |

- 覆盖前自动备份成 `<名>.bak_<时间戳>.mat`。
- **为什么 Mask.mat 是 3D**：② 的 `apply_mask` 是 MATLAB 口径 `img .* Mask - (~Mask)`，
  MATLAB 有隐式扩展（2D 掩模自动按第 3 维展开）、numpy 没有 → 2D 会广播报错。
  ④ 读 3D 时取第 1 层，与 2D 完全等价。

### 4.2 与 MATLAB 已有结果的对照（实测 2026-10-01，c1 / h1）

| 项目 | c1 | h1 |
|---|---|---|
| 底图 `mean(S0,3)` vs `img_mask_base` | max\|diff\| = 0 | max\|diff\| = 0 |
| `liverMask` vs 参考（体素） | 8847/8847，差异 0，Dice 1.000000 | 10051/10051，差异 0，Dice 1 |
| `snrMask` vs 参考 `Thmask.mat` | 26823/26823，max\|diff\| = 0 | 27959/27959，max\|diff\| = 0 |
| 最终 `Mask` vs 参考 `mask.mat` | max\|diff\| = 0 | max\|diff\| = 0 |
| 参考反推噪声 σ（阈值 = 15σ） | 25.7933（386.899） | 16.3333（245.0） |

```powershell
# 复现（用参考 liverMask + 参考 σ 跑一遍模块）
python "…\CEST_Studio\tools\validate_mask.py" --reproduce
# 体检你手画的结果
python "…\CEST_Studio\tools\validate_mask.py" --check --proj "…\_roi_mask_proj"
```

手画的掩模不会和参考差 0 体素（人是画不准的），差异应集中在边界几个体素；脚本会报
差异体素数 + Dice，Dice 一般要 > 0.98 才算画得干净。

## 五、报错 / 提示速查

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 读不到底图 s0 | 底图目录里没有 `s0.mat` / `*_interp.mat` | 先在 ① 跑重建，或把「底图」指到正确目录 |
| 打不开画布 | 同上 | 同上；弹窗里写了具体路径 |
| 还没有掩模：点【打开掩模画布…】画一张，或【载入已有掩模…】 | 没画也没载入就点了开始 | 先画或先载入 |
| 噪声区是空的 | 画了噪声区目标但没涂 | 在背景拖个矩形，或把「噪声 σ」手输一个值 |
| 既没有噪声区也没有 σ → snrMask 置全 1 | 没画噪声区、σ 也是 0 | 想在屏幕上画噪声区，或手输 σ；不填也能存，但不做 SNR 过滤 |
| `Mask.mat` 形状 (X,Y) ≠ 底图 (X,Y) | 掩模和底图不是同一批数据 | 检查「底图」和掩模文件是不是同一个病例/同一层数 |
| 载入的掩模里没有 liverMask / Mask，只有 SNR 掩模 → 直接当最终掩模 | 只给了 MATLAB 的 `Thmask.mat` | 想要 MATLAB 那套组合掩模就改选 `mask.mat` |

## 六、别踩的坑

1. **`Mask.mat` / `Thmask.mat` 存的是 3D**，MATLAB 参考文件是 2D；对拍时取任一层。
2. **`Thmask.mat` 的含义两边不同**：MATLAB 的 = SNR 掩模（不被覆盖）；Python 的 = 组合掩模。
   ⑧ 另存 `snrMask.mat` 保全信息。
3. **底图下拉框只影响显示**，SNR 永远按层间平均算。
4. **`00_掩模` 是横切目录**：②③④ 都优先从这里取；换个病例就换 `00_掩模\<病例>\`。
5. 画布里的坐标是 **0 基图像像素坐标 (列, 行)**，和核心层 `points_to_mask` 一致；
   多边形顶点落在像素中心判内，实测与 MATLAB `roipoly` 等价（差异 0 体素）。
6. **默认停在 `★ 全层平均` 上画就够了**（一张 20 层共用，与 MATLAB 口径一致）；
   「本层单独保存」是**覆盖式**的：那一层完全用它自己那张，不跟共用张求并集。
7. **色图只是观感**：MATLAB 画噪声用灰度、画组织用默认 parula、画器官 ROI/出图用 jet 首行黑，
   本画布切目标会自动对应；掩模结果与色图无关，换色图不会改任何数值。

## 七、画器官 ROI（ROI_total，③ 后处理要用）

> 对应 MATLAB `runCESTpost.m` 的 `nROI/target_freq` + `ROI_name.m` + `ROIplotSong_0708.m`。
> 和掩模在**同一个画布**里画，产物也在**同一个目录** `PROJ\00_掩模\<病例>\`。

### 7.1 先决条件
- **必须先有去噪掩模**（没有会被拦下）。掩模不用重画：打开画布时会自动把
  `00_掩模\<病例>\liverMask.mat / snrMask.mat` 当底稿带进来，你只画 ROI 也不会动掩模。

### 7.2 ⑧ 页参数（新增 4 个）

| 参数 | 默认 | 说明 |
|---|---|---|
| `ROI 数量（器官 ROI）` | 1 | = MATLAB `nROI`；画布按这个数量生成 ROI1…ROIn。**在 ⑧ 页「参数」区第 3 行**；画布里也有一个同名的快速入口（+【应用】） |
| `ROI 目标 ppm` | 3.5 | = MATLAB `target_freq`；ROI 底图取这个 ppm 的 Z 谱 |
| `ROI 显示` | `Z 原始（APT）` | `Z 原始（APT）`（= MATLAB `roi_display_mode 1`）/ `1−Z（ST）`（= `mode 2`） |
| `ROI 色标下限 / 上限` | 留空 | 留空 = 自动（0 / 有效值 95% 分位）；画布上也能改 |

### 7.3 怎么画（动线）
1. ⑧ 页把 `ROI 数量` 设好（默认 1；在「参数」区第 3 行）→ 点 **【打开掩模画布…】** 或 **【重新画 ROI…】**。
   （也可以在画布里直接改：右侧「掩模对象」组的 **`ROI 数量` +【应用】**，改完立刻增删 ROI1…ROIn；
   减少数量会丢掉末尾 ROI 的勾画，会先问你一下。）
2. 右边「掩模对象」里选中 **ROI1**（列表最下面几个）→ 底图自动切成
   「**ROI 底图：Z 层均 × 掩模**」，色图自动 jet（首行黑）。
   想看反相（ST）就在「底图」组里把 **`ROI 显示`** 切到 **`1−Z（ST）`**（= MATLAB `roi_display_mode 2`）；
   切完色标会自动按新图重算初值。`ROI 显示` 旁边只有选中 ROI 时才可用。
3. 和画掩模一样：多边形（左键加点、**双击确定**、右键/Backspace 撤点）、矩形、画笔、橡皮；
   画完自动切到「选择/拖动」，可以拖顶点、整体挪、右键删顶点；撤销 30 步。
4. **色标想改随时改**：右侧「色标」上/下两个框，或点【自动(95%分位)】；改一下就立刻刷新
   （只影响观感，不影响 ROI 形状，也不影响存出来的索引值）。
5. 有多个 ROI 就点 ROI2 / ROI3… 接着画（MATLAB 也是这样一个个来）。
6. 【确定】→ ⑧ 页【开始】。

### 7.4 复用还是重画
- **默认沿用**：目录里已经有 `ROI_total.mat` → 【开始】时不重画（照 MATLAB 的 `try/load`）。
- **要重画**：点【重新画 ROI…】→ 画布上改完确定 → 下次【开始】覆盖重画（旧文件自动备份）。

### 7.5 产物（`PROJ\00_掩模\<病例>\`，和掩模同目录）

| 文件 | 变量 | 内容 |
|---|---|---|
| `ROI1.mat` / `ROI2.mat` … | `ROI` | 每个 ROI 的 (X,Y) 0/1（与 MATLAB 同名同变量） |

### 7.6 报错 / 提示

> 右侧栏宽度是按内容自适应的，并已关掉横向滚动条 —— 不需要左右滑。

| 提示 | 意思 / 怎么办 |
|---|---|
| 「ROI 需要先有去噪掩模」 | 先在本页把掩模画好或载入，再画 ROI |
| 「ROI<k> 与去噪掩模没有交集，请重新勾画」 | 画到掩模外面去了（掩模外是 0） |

| `ROI1.mat` 不出现 | 只画了 ROI 但还没点【开始】，或这轮是「沿用」模式 |

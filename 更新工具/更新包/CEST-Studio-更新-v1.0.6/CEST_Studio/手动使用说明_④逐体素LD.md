# ④ 逐体素LD（洛伦兹拟合）—— 手动使用说明

> 底层 = `03_Python_全链路\函数库\cest_ld.py`（`normalize_spect0916` / `voxel_ld_filter_fast|voxel_ld_filter`），
> **核心层一行不改**。对应 MATLAB `make_voxel_ld.m` + `processLD_0909.m` + `Voxel_LD_filterV0909.m`。

---

## 一、它是什么 / 什么时候用

把每个体素的 Z 谱按 **洛伦兹模型** `y = par4 − par2/(1+4((x−par1)/par3)²)` 拟合，
得到 **LD 信号**（拟合残差），再用它出 `LD / NOE / Glyco` 那类图（② 的 LD 模式）。

**依赖**：

| | |
|---|---|
| **必须** | `PROJ\00_掩模\<病例>\Mask.mat`（去噪掩膜）→ **没有就拦下**，先去 ⑧ 画/载入 |
| 数据 | `PROJ\01_重建\<病例>\`（`w_offset.mat` / `ssat.mat` / `s0.mat`） |
| 不需要 | `ROI_total.mat`（拟合不需要器官 ROI） |

## 二、主页面（常用参数）

| 参数 | 默认 | 说明 |
|---|---|---|
| `输入（重建结果）` | — | 指到 `PROJ\01_重建\<病例>` |
| `病例名` | 自动 | 输出 `04_逐体素LD\<病例>\`；取掩模也按它 |
| `掩模文件` | 自动 | 找 `00_掩模\<病例>\Mask.mat` |
| `掩模取第几层` | 1 | 拟合只吃**一张 2D 掩模**（MATLAB 用 `Mask(:,:,1)`） |
| `拟合算法` | **fast** | fast = 网格+闭式解（≈1.7 s/层）；exact = 逐体素 lsqcurvefit 等价（分钟/层） |
| `层` | 留空=全部 | 填 `1` 只算第 1 层（试跑），或 `1,3,5` |

**其余 ~29 项都在【高级参数…】里**（见第三节）。

## 三、高级参数（① 页面板 / 参数区的【高级参数…】按钮）

按 5 组：

### 三个拟合区间
`l3 ~ l2`（低端段，默认 **-10 ~ -6**）、`l1 ~ h1`（中段，**-0.6 ~ 0.6**）、`h2 ~ h3`（高端段，**6 ~ 10**）。
必须满足 `l3 < l2 < l1 < h1 < h2 < h3`（不满足会当场报错）。

### 洛伦兹拟合
模型参数顺序 = **中心 c, 幅度 A, 线宽 g, 基线 b**。

- `lb₁…lb₄`（默认 `-inf, -inf, 0, -inf`）、`ub₁…ub₄`（默认 `0, inf, 1.8, inf`）
- `par0₁…par0₄`（默认 `0, -50, 20, 1`；`20` 超过线宽上界时会被夹到 1.8）
- `中心固定为 0（MATLAB 口径）`：勾上 = `lb₁=ub₁=0`
- `对称性剔除阈值`（默认 5.0）

**预设按钮**（一键切）：
`MATLAB 默认` / `无下界 lb=[]`（MATLAB 新版）/ `processLD_0909 版`（`lb=[0,-Inf,0,1]`）/
`GenAll 线宽 1.7` / `区间·NEG` / `区间·POS` / `中心固定 0`。

### 拟合网格（fast）
`中心网格 起点/步长`（默认 `-2.0` / `0.05`）、`线宽网格 起点/步长`（默认 `0.2` / `0.05`）。
网格空（起点 ≥ 上界）会当场报错。

### 归一化
`tol`（默认 0.05）：已在 `[0,1]±tol` 就跳过「除 S0」。
> 核心层固定：**分位 1/99、只裁剪不重标定**（与 MATLAB `normalizeSpect0916(z,tol,1,99,false)` 一致）——
> 这两个值没有放开；要放开得改核心层。

### 输出与插值
`拟合后插值步长`（0.1）、`插值方法`（spline，仅 exact 用）、`写 voxel_LD_interp.mat`（开）、
`调试·每层最多体素数`（留空=不限；填 200 可秒出结果看效果）。

**另**：`恢复默认` / `载入预设…` / `保存为预设…`（存到 `PROJ\_预设\m4_ld_<名>.json`）。
按【确定】会先做整页校验（区间递增、lb≤ub、网格非空、掩膜存在…），有问题会列出来并问你要不要照旧关闭。

## 四、跑完得到什么

`PROJ\04_逐体素LD\<病例>\`：

| 文件 | 变量 | 说明 |
|---|---|---|
| `0.7ut_img_interp.mat` | `s0 / b0 / norm_z=img_interp / w` | 归一化后的数据（**② 直接复用**，省得自己再生成一份） |
| `voxel_LD.mat` | `voxel_ld` / `Voxel_LD_all` | 拟合残差 `[X,Y,层,频]`（② 的 LD 模式用它） |
| `voxel_LD_interp.mat` | `voxel_ld_interp` / `…_all` / `w_offsetLD_interp` | 密网格版（≈300 MB；可关） |
| `_thmask_used.mat` | `Thmask` | 本次**实际用**的 2D 掩模（留痕） |
| `ld_check.png` | — | 质检图：LD 中层切片 / \|LD\| 结构 / 每层线宽中位数 |
| `ld_meta.json` | — | 全部参数 + 每层耗时/有效体素/线宽中位数 |

- 同名重跑**先备份** `.bak_<时间戳>`。
- 跑的时候是**后台线程**：有进度条（第 k/20 层）、日志每层一行、【取消】在下一次检查点生效。

## 六、验收 / 自查

```powershell
# 1) 壳的编排 == 核心层 make_voxel_ld（逐位一致）
python CEST_Studio\tools\validate_ld.py --parity --src <重建结果目录> --mask <Mask.mat> --proj <PDIR> --layers 1 --max-voxels 300

# 2) 与 MATLAB 参考对拍
python CEST_Studio\tools\validate_ld.py --check --ours <ours\voxel_LD.mat> --ref <ref\voxel_LD.mat>
```

实测（2026-10-02）：
- **对拍核心层：逐位一致**（`voxel_ld` 与 `img_interp` 的 `max|diff| = 0`）。
- **h1 全 20 层**（fast）：总耗时 ≈ 33 s（1.6 s/层，10076 个有效体素）。
- **与 MATLAB 参考** `2026\09\CEST_result\h1\voxel_LD.mat`：有效体素图样一致 **0.9995**、Dice **0.9992**、
  交集上中位差 **0.0076**（第 20 层 0.20 / 相关 0.79，与交接文档记录一致）。
  → fast 是**全局最小二乘解**，MATLAB 是 **LM 局部解**，两者本就"略有差异"；要逐点更贴近 MATLAB 就选 `exact`（慢）。

## 七、报错 / 提示

| 提示 | 怎么办 |
|---|---|
| 「④ 需要去噪掩膜…」 | 先去 ⑧ 画好/载入掩模 |
| 「三个拟合区间要低→高递增…」 | 改区间，让 `l3<l2<l1<h1<h2<h3` |
| 「搜索网格是空的」 | 检查 `中心/线宽网格 起点` 是否 ≥ 对应的 `ub` |
| 「输入目录里没有 ① 的产物」 | `输入` 指到 `PROJ\01_重建\<病例>` |
| 「层号超出范围」 | `层` 填 `1~20` 内的整数 |
| 「掩模形状 … 与数据 … 不一致」 | 掩模和数据的 X/Y 不是同一套（选错病例了？） |
